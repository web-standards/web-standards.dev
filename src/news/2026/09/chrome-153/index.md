The `<camera>` and `<microphone>` elements request video and audio capture declaratively, with browser-controlled UI and permission recovery. The `overflow` property now takes scrollable values next to `clip`, so `overflow: scroll clip` makes a scroll container on one axis. The new `scroll-axis-lock` property controls diagonal scrolling. JavaScript gains `Iterator.zip()` and `Iterator.zipKeyed()` to aggregate several iterators.
