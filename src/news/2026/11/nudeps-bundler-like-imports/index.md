Lea Verou introduces a tool that lets you import npm packages by name in the browser without a bundler. It copies only the needed files from `node_modules` to `client_modules` and generates an import map, never touching your own code. It works with Vue, React, Lit, D3, and even CJS packages. It doesn’t transform code, so JSX and TypeScript still need compilers, and only npm is supported for now.
