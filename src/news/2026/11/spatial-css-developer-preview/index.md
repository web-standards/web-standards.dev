Brandel Zachernuk presents a preview of the proposed spatial CSS API in Safari on visionOS 27.3, behind the CSS Portals flag. It extends existing syntax for 3D `<model>` elements: `spatial: portal` makes an element a shared 3D space, `transform` moves models inside it, `position-anchor` attaches one model to another, `@environment-map` sets lighting from HDR images, and `portal-action: orbit` lets users rotate the scene.
