HTML-in-canvas draws real HTML into `<canvas>`. The new `corner` shorthand sets `border-radius` and `corner-shape` at once, `text-overflow` takes a custom string for clipped text, and `position-visibility` gets the `anchor-valid` and `anchor-visible` values. Methods like `appendHTML()` replace `insertAdjacentHTML()`, `streamHTML()` parses HTML as it arrives, and Long Animation Frames report style and layout time.
