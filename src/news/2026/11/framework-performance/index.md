A new project by e18e benchmarks nine meta-frameworks, from Astro and Next.js to Nuxt, SvelteKit, and TanStack Start: dependencies, install and build times, server throughput, and Core Web Vitals. Astro ships just 3KB on initial load and handles 767 requests per second. Next.js ships 140KB, handles 145, and is the only one that still ships `core-js` polyfills. The tests run in CI for every new version.
