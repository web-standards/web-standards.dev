On-device speech recognition with the Web Speech API now works on desktop for real-time speech-to-text in 40 languages. WebTransport gets custom request headers, byte streams for datagrams, and new buffering options. The `::-webkit-input-placeholder` pseudo-element now works as an alias of `::placeholder`. Behind flags: `blocking="render"`, lazy loading for `<video>` and `<audio>`, and the `Speculation-Rules` header.
