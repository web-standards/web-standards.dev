Sacha Greif and Devographics polled 4,902 developers, and anchor positioning came out as the year’s favorite new feature, topping both the wish list and the browser support complaints. View Transitions and `if()` hit the same wall. CSS also resists AI, with only 28% of code generated on average, well below other stacks. Positioning, `:has()`, and `@container` size queries lead the pain points.
