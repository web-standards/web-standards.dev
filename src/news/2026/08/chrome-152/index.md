The `CSSPseudoElement` interface now covers `::backdrop`, `::scroll-marker`, and `::view-transition`, so clicks on a dialog backdrop or a scroll marker finally have a target. The new CPU Performance API reports the performance tier of a device, and the `Connection-Allowlist` header restricts where a page can send requests. CSS also gains the `alpha()` function for relative transparency, and the `autocorrect` attribute lands on editable fields.
