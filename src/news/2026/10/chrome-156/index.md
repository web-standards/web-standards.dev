CSS gets the `random()` function for values in a range, the `:navigation-source` pseudo-class for the link, button, or form that started a navigation, and the `pair` keyword for `scroll-snap-type` to snap both axes to the same element. Overflow accepts `scroll clip` for single-axis scrolling. Failed module imports are no longer cached, so `import()` can retry, WebTransport supports custom headers, and IndexedDB moves to a SQLite backend.
