Temani Afif shows how a parent can know how many children it has. The `sibling-count()` function counts siblings, not children, so he adds an extra element sized with `sibling-count()` and uses scroll-driven animations with `view-timeline` and `timeline-scope` to turn its width into a `--n` variable on the parent. Use it for item counts, square-ish grids with `sqrt()`, or circular layouts. Works in Chrome and Edge for now.
